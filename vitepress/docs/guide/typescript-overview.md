# TypeScript Overview

Consumers can import the public declaration-backed entries: `nodula-framework`, `nodula-framework/form`, `nodula-framework/router`, and `nodula-framework/animation`. The declarations are emitted next to their JavaScript bundles.

TypeScript is not needed at runtime and does not change Nodula's JavaScript implementation. Template script blocks are JavaScript-only. The repository's type tests illustrate supported signal, DOM, form, router, and animation types.
